## Michele Salla · Desafio 7 em 7
Página de vendas em HTML + CSS (em aprovação), que depois vira um JSON do Elementor.

- `michele-salla/desafio-7em7/pagina-A.html` · promessa "Perca até 7cm de barriga em 7 dias…"
- `michele-salla/desafio-7em7/pagina-B.html` · promessa "Chega de se sentir mal diante do espelho"
- Para editar: mude `_modelo.html` ou `styles.css` e rode `python3 build.py` (gera A e B).
- `assets/img/` tem as imagens usadas; `assets/src/` tem os originais do site da Michele.
- `prints/` tem os testes em 390px e 1200px.
